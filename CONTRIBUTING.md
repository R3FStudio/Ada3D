# Contributing to Ada3D

For a bug report, include the Ada3D version, operating system, reproduction steps and expected result. Attach a screenshot or small project when it helps.

For code changes, see the [source map](docs/source-map.md) and [build instructions](docs/platforms.md). Keep each pull request focused on one change. Include relevant tests and screenshots for interface changes.

Run formatting, Clippy and tests before submitting. Contributions are provided under the project's GPLv3 license.
